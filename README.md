 Setup Instructions
 Clone the Repository
To get started, clone the repository from GitHub:


git clone https://github.com/your-username/interactive-map-project.git  
cd interactive-map-project  

 Install Dependencies
Run the following command to install all necessary dependencies:

npm install  


npm run dev  
This will start the Vite development server. Open the provided URL in your browser.

npm run build  
This will generate an optimized dist/ folder for deployment.

To test the production build locally:

npm run preview  


🗺️ Usage Instructions
🌍 Search Locations

Type a city name in the search box and press Enter.
Click on a search suggestion to center the map on that location. Pop up function that fetches chosen spots information

📍 Add Custom Markers
Click anywhere on the map to drop a marker and get location details.
A popup will appear with latitude, longitude, and location info.

🌓 Toggle Dark Mod
Click the Dark Mode button to switch between light and dark themes.

Reset-
Resets map and poinst towards new york

➕ Zoom Controls
Click Zoom In or Zoom Out buttons to adjust the map view.
